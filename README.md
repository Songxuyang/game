# 重力翻转小人

一个打开浏览器就能玩的轻量小游戏。点击、触摸或按空格翻转重力，让方块小人在不断向左移动的平台之间生存。

使用单文件 HTML、Canvas 2D 和原生 JavaScript 实现，无外部依赖，无需安装或构建。

## 开始游戏

1. 下载本仓库，或通过 Git 克隆：
   ```bash
   git clone https://github.com/Songxuyang/game.git
   ```
2. 用现代浏览器打开仓库中的 `index.html`。
3. 点击画布或按空格开始；手机上触摸画布即可开始。

游戏支持离线运行，不需要启动服务器。

## 操作方式

| 输入方式 | 开始界面 | 游戏中 | 结束界面 |
| --- | --- | --- | --- |
| 鼠标左键点击画布 | 开始游戏 | 翻转重力 | 重新开始 |
| 触摸画布 | 开始游戏 | 翻转重力 | 重新开始 |
| 空格键 | 开始游戏 | 翻转重力 | 重新开始 |

## 游戏规则

- 小人的水平位置固定，只能沿上下方向运动。
- 初始重力向下，每次操作都会翻转重力并施加一个小冲量。
- 重力向下时可以落在平台上表面；重力向上时可以贴住平台下表面。
- 平台持续向左移动。站立期间小人的水平位置保持固定，平台移出脚下后，小人会继续受重力影响。
- 每成功站上一个新平台获得 **1 分**，同一平台只计分一次。
- 随着得分增加，平台移动速度会逐渐提高，达到上限后保持不变。
- 小人越过画布上边界或下边界时游戏结束，点击、触摸或按空格可以重开。

最高分保存在当前浏览器的 `localStorage` 中，键名为 `gravity_flip_best`。清除浏览器数据可能会清除纪录；如果浏览器禁止本地存储，游戏仍能运行，但最高分可能无法在刷新后保留。

## 技术实现

- **逻辑画布**：480 × 720，等比缩放以适配桌面和手机屏幕。
- **游戏循环**：使用 `requestAnimationFrame`，单帧时间步长限制为 0.033 秒。
- **游戏状态**：开始界面、游戏中、游戏结束。
- **碰撞检测**：AABB 检测结合跨平台表面检测，减少高速运动时的穿透。
- **资源**：全部由 Canvas 绘制，使用系统字体，无外部图片、字体或音效。
- **输入处理**：阻止空格和触摸造成页面滚动，过滤按键重复与触摸产生的兼容鼠标事件。

## 调整参数

游戏参数集中在 `index.html` 的 JavaScript 顶部，修改后刷新页面即可生效。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `PLAYER_SIZE` | 28 | 小人尺寸 |
| `GRAVITY` | 1600 | 重力加速度 |
| `MAX_VY` | 650 | 最大垂直速度 |
| `FLIP_IMPULSE` | 200 | 翻转时的初始垂直速度 |
| `BASE_SPEED` | 140 | 平台初始移动速度 |
| `SPEED_PER_SCORE` | 6 | 每得 1 分增加的移动速度 |
| `MAX_SPEED` | 300 | 平台移动速度上限 |
| `MAX_VERTICAL_DELTA` | 260 | 相邻平台的最大高度差 |
| `MIN_GAP` / `MAX_GAP` | 180 / 300 | 平台生成间隔参数 |

## 版本范围

当前为 **MVP v1.0**，专注重力翻转、平台碰撞、计分和本地最高分。暂不包含联机、排行榜、音效、皮肤、关卡编辑器或服务器存储。
