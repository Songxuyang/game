# 重力翻转小人 v1.4

一个打开浏览器就能玩的轻量小游戏。玩家以有头、身体和四肢的小人呈现，向上重力时会倒立，皮肤预览同步显示小人形象；碰撞范围仍为原来的 28 × 28 矩形。点击、触摸或按空格翻转重力，让小人在不断向左移动的平台之间生存。

使用单文件 HTML、Canvas 2D 和原生 JavaScript 实现，无外部依赖，无需安装或构建。

## 开始游戏

1. 下载本仓库，或通过 Git 克隆：
   ```bash
   git clone https://github.com/Songxuyang/game.git
   ```
2. 用现代浏览器打开仓库中的 `index.html`。
3. 点击画布或按空格开始；手机上触摸画布即可开始。

游戏支持离线运行，不需要启动服务器。

## v1.4 新增

本次仅增加皮肤动画，不改变玩家物理、平台生成、碰撞、金币计分、钱包和难度。

- **玩家呼吸光晕**：游戏中随皮肤颜色缓慢呼吸，开始和结束界面不显示，绘制时避开顶部计分区域。
- **金币闪光与浮动**：轻微上下浮动、左上高光弧线与外圈柔光；碰撞始终使用金币原始坐标。
- **翻转冲击波**：成功翻转时出现短暂扩散圆环，0.28 秒内消失，同时最多 8 个。
- **背景氛围**：开始、游玩、结束和查看面板期间，视觉时间持续前进。重开不重置视觉时间，换肤立即清空并重建背景特效。
- **动画开关**：皮肤面板的“动画特效”按钮或 **T** 键切换，刷新后保留设置。关闭后清空冲击波和背景粒子，保留原有翻转/得分/金币/死亡粒子及音效。
- **自动降级**：每 2 秒评估帧耗时指数平均，低于 40fps 时降一级；持续高于 55fps 满 4 秒后，在评估时升一级。等级不跨刷新保存。

## 保留的 v1.2 功能

- **合成音效**：翻转、平台得分、金币、连击、死亡和成就使用 Web Audio 实时合成，不加载音频文件。点击右上角“音效”或按 **M** 切换，刷新后保留设置。不支持 Web Audio 时静默运行。
- **尖刺障碍**：符合条件的较宽普通平台可能带红色顶面尖刺，两端保留安全区；初始平台和移动平台没有尖刺。碰到尖刺或被移动中的尖刺扫到都会结束游戏，底面仍可吸附。
- **成就系统**：右上角“成就”按钮或 **A** 打开面板，点击面板、关闭按钮或按 **A / Esc** 返回。查看期间游戏冻结，关闭后继续，不消耗存活和连击时间。
- **解锁反馈**：成就解锁后显示提示并播放短音，同时最多显示一条，新提示替换旧提示，2 秒后淡出。成就和累计统计保存在当前浏览器。

## 游戏规则

- 小人的水平位置固定，只能沿上下方向运动。
- 初始重力向下，每次操作都会翻转重力并施加一个小冲量。
- 重力向下时可以落在平台上表面；重力向上时可以贴住平台下表面。
- 平台持续向左移动。站立期间小人的水平位置保持固定，平台移出脚下后，小人会继续受重力影响。
- 每成功站上一个新平台获得 **1 分**，同一平台只计分一次。连续踩新平台会累积连击，从第 3 连击起，每次踩新平台获得 **2 分**。
- 超过 4 秒未踩新平台，连击归零；收集金币不延长连击时间，也不打断连击。结束界面显示本局最高连击。
- 金币有 60% 概率随新平台生成，收集获得 **1 分**，不享受连击奖励。金币以平台水平速度的 85% 左移，与平台存在相对位移。
- 绿色是普通平台，蓝色是上下摆动的平台；站上蓝色平台时，小人会跟随其上下移动。
- 随着得分增加，平台会逐渐变窄、生成间隔缩小、相邻高度变化范围扩大，移动平台出现概率提高；难度系数在 30 分时达到上限。水平速度上限为 340 px/s。
- 小人越过画布上边界或下边界时游戏结束，点击、触摸或按空格可以重开。

最高分保存在当前浏览器的 `localStorage` 中，键名为 `gravity_flip_best`。清除浏览器数据可能会清除纪录；如果浏览器禁止本地存储，游戏仍能运行，但最高分可能无法在刷新后保留。

## 技术实现

- **逻辑画布**：480 × 720，等比缩放以适配桌面和手机屏幕。
- **游戏循环**：使用 `requestAnimationFrame`，单帧时间步长限制为 0.033 秒。
- **游戏状态**：开始界面、游戏中、游戏结束。
- **碰撞检测**：AABB 检测结合玩家与平台的相对跨面检测，减少高速运动和平台摆动造成的穿透；金币使用圆与矩形的最近点检测。
- **反馈**：翻转、踩新平台、金币和死亡分别触发粒子。结束后游戏世界冻结，死亡粒子短暂播放后消失。
- **资源**：游戏主体由 Canvas 绘制，设置、成就/皮肤面板与提示使用 DOM。采用系统字体和 Web Audio 合成音效，无外部资源。
- **输入处理**：阻止空格和触摸造成页面滚动，过滤按键重复与触摸产生的兼容鼠标事件。

## 版本范围

当前为 **MVP v1.4「皮肤动画特效」**，在 v1.3 的钱包、皮肤和页面视觉基础上增量扩展。保留动态难度、移动平台、金币、连击、粒子、尖刺、音效和成就，继续保持单文件、无依赖和离线运行。

难度系数为 `min(score / 30, 1)`。平台宽度从约 200–240 缩小到 110–150，移动平台概率从 0% 增至 35%，摆动幅度为 40–100 像素。尖刺仅在难度系数不低于 0.15、宽度不小于 160 的普通平台按概率生成；满难度下平台宽度低于此门槛，因此不会生成尖刺。

本局最高连击不跨局保存；最高分、成就、音效设置、累计统计、钱包、已解锁皮肤、当前皮肤与动画开关持久化保存。存档读取会校验钱包数值和皮肤 ID，非法或未解锁的当前皮肤会回退到经典黄。暂不包含排行榜、联机、关卡编辑器或服务器存储。
